# v1.11.0 — M27: corpus-derived query expansion, measured and rejected

**Phase:** M27 · **Requirement:** FR-17 · **Report:** `results/expansion.md` ·
**Regenerate:** `python -m eval.expansion` (or `make expansion`).

## What was built

`src/atlas/expand.py`: a pointwise-mutual-information table over the tenant's own chunks, built
from the token sets the view already holds for coverage. A query term is expanded with the terms
it co-occurs with more often than their frequencies predict — no model, no key, no training
corpus. It is wired into the retrieval query only: the refusal gate still reads the question as
asked, so a corpus word cannot launder an unknown topic into a pass.

Shipped **off** (`expansion_threshold = 0.0`). The experiment is the deliverable; the feature is
not.

## What it measured

Fit on v1 (the smallest threshold that costs v1 neither an answer nor a refusal — 2.5, 0.73 terms
added per query), decide on v3:

| set | answer before | after | refusal before | after |
|---|---|---|---|---|
| v1 | 0.9583 | **1.0000** | 0.8333 | 0.8333 |
| v2 | 0.9167 | 0.9167 | 0.5000 | 0.5000 |
| v3 | 1.0000 | 1.0000 | 0.6667 | **0.5000** |
| v4 | 1.0000 | 1.0000 | 0.6667 | 0.6667 |

The v1 gain and the v3 loss are the same mechanism: v3-016's confidence rises 0.3048 → 0.4031 on
the strength of `150, advance, break`, and 0.4031 clears theta. A stray numeral and two unrelated
words turned an unanswerable question into an answered one. At 0.5 the effect is far worse — v1
refusal 0.8333 → 0.3333 for 14.77 added terms per query — which is the failure the literature
predicts when queries are already lexically aligned with the corpus.

## Decision

**Not adopted.** FR-17 stays open, with the numbers attached. The rule was fixed before the run:
v3 must improve and no answerable question may be lost. v3 did not improve; it got worse. The
shipped default remains `expansion_threshold = 0.0`, so no committed answer changed and
`make determinism` stays at 0 differences.

The ceiling is the corpus itself: a term the corpus never uses has no neighbours, so the questions
expansion should help most are exactly the ones it cannot touch. That is L22.
